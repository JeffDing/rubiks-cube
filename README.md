# 三维魔方（Rubik's Cube）

一个纯前端的 3D 魔方小游戏，基于 three.js 渲染。无需安装、无需联网、无需构建，**任何有浏览器的平台都能直接运行**。

## 如何运行

三种方式任选其一：

1. **直接双击打开（最简单，推荐）**
   进入 `rubiks-cube` 文件夹，双击 `index.html`，即可在浏览器中开始游戏。
   three.js 已内置在 `js/three.min.js`，完全离线可用，可整个文件夹拷贝到任意电脑 / 手机使用。

2. **本地起服务运行**
   ```bash
   cd rubiks-cube
   python3 -m http.server 8000
   # 浏览器访问 http://localhost:8000/
   ```

3. **部署到任意静态托管**
   把整个文件夹上传到 GitHub Pages / Gitee Pages / Nginx / OSS 等静态托管即可。

## 操作方式

| 操作 | 效果 |
| --- | --- |
| 拖动贴纸 | 转动对应层（与真实魔方一致，抓住哪里转哪里） |
| 拖动空白处 / 右键拖动 | 旋转整体视角 |
| 滚轮 / 双指捏合 | 缩放 |
| 键盘 `U D L R F B` | 转动对应面（配合 `Shift` 反向） |
| 底部按钮 | 打乱、智能还原、瞬间复原、重置视角 |

- **打乱**：随机 22 步，之后开始计时与步数统计。
- **智能还原**：根据操作历史逆序逐步演示还原过程（保证还原，步数为操作步数，非数学最短解）。
- **瞬间复原**：立即回到还原状态（无动画）。

```
├── README.md       本说明
└── js/

```

## 实现要点

- 魔方状态以 26 个小块的「整数坐标 + 3×3 朝向矩阵」为唯一真相，旋转用整数矩阵运算，无浮点漂移。
- 拖动转层通过命中贴纸的世界法线与屏幕拖动向量，投影到两个切向立方体轴来确定「旋转轴 / 层 / 方向」，与真实魔方握持一致。
- 还原判定：所有贴纸的世界朝向等于其初始朝向即为还原。
